# Herramientas WorkMate

[CSV MATCH](CSV-MATCH/README.md) compara y busca valores en CSV y XLSX directamente en el navegador. Descarga el repositorio y abre `CSV-MATCH/index.html` para usarlo sin servidor ni conexión.

El código propio se distribuye bajo la [licencia MIT](LICENSE). El lector XLSX incorpora SheetJS Community Edition bajo [Apache 2.0](CSV-MATCH/js/vendor/SheetJS-LICENSE.txt).
